Функция print_proc_maps() читает и выводит содержимое /proc/self/maps (где self — текущий процесс), позволяя видеть текущее отображение памяти, включая загруженные библиотеки.

В main() сначала выводится отображение процесса без загруженной библиотеки.

Затем библиотека libmylist.so загружается вызовом dlopen().

После загрузки снова выводится содержимое /proc/self/maps — здесь появятся записи, соответствующие libmylist.so.

Далее библиотека выгружается dlclose().

Выводится отображение снов — записи о libmylist.so исчезнут при успешной выгрузке.

Такой подход наглядно демонстрирует изменение адресного пространства процесса при динамической работе с библиотеками.

Если запускать этот код из терминала, можно наблюдать в выводе строки с путём ./libmylist.so в разных сегментах памяти.

Важные замечания:
Библиотека должна существовать в текущей директории или указанном пути.

libmylist.so — это собранная с флагами -fPIC shared library.

dlopen с флагом RTLD_NOW немедленно разрешает все символы.

dlclose лишь уменьшает счётчик ссылок, физическая выгрузка произойдёт, когда все ссылки закроются.

Иногда библиотека может не выгружаться сразу в maps, если ссылки остались или кэшируется.
