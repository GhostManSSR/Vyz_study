# Эксперименты и отчёт

## Условия эксперимента

- Изображений: **60**; набор состоит из PNG трёх размеров: 320x240 (20 шт.), 800x600 (20 шт.), 1280x720 (20 шт.).
- Обработка: фильтр `grayscale`; замер включает запуск рабочих потоков, чтение, обработку и запись PNG.
- Режимы: 1, 2, 4 и 8 потоков; каждый запуск повторён 3 раза.
- Перед каждым запуском выходной каталог очищался.
- Среда: Linux-6.6.87.2-microsoft-standard-WSL2-x86_64-with-glibc2.39, Python 3.12.3.

## Вывод

Для набора из 60 изображений среднее время последовательной обработки составило 2.465 с. Ускорение многопоточных режимов рассчитано относительно этого значения. Результат зависит от числа доступных ядер, дисковой подсистемы и размера изображений.
