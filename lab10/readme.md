taskset — это утилита в Linux для привязки (аффинити) процесса к определённым ядрам процессора. Обычно ОС Linux распределяет процессы по всем доступным ядрам, но иногда полезно ограничить процесс одним или несколькими ядрами для:

Повышения предсказуемости производительности,

Изоляции нагрузки на ядра,

Тестирования многопоточных программ под разной нагрузкой на ядра.

Основные возможности и примеры:
Просмотр аффинити процесса:

bash
taskset -p <pid>
Запуск процесса на определённых ядрах (маска CPU — битовая маска ядёр):

bash
taskset 0x01 ./my_program  # запустит на ядре 0
taskset 0x03 ./my_program  # ядра 0 и 1
Изменение аффинити уже запущенного процесса:

bash
taskset -pc 0,2,3 <pid>
где номера ядер — через запятую или диапазон через дефис.

taskset -c 0 ./app1

Алгоритм Петерсона
Это классический программный алгоритм для организации взаимного исключения между двумя потоками без использования блокировок ОС.

Суть алгоритма
Два потока используют две булевые переменные (flag[0] и flag[1]), показывающие, хочет ли поток войти в критическую секцию, и переменную turn, указывающую, чей сейчас ход.

Как он работает
Поток: выставляет свой флаг в true — маркирует желание войти в критическую секцию,

Записывает в turn идентификатор другого потока — даёт ему шанс первым войти,

Ждет, пока другой поток не откажется от входа или не отдаст ход,

Заходит и выполняет критическую секцию,

В конце сбрасывает свой флаг.

Ключевые свойства
Обеспечивает взаимное исключение (в один момент в критической секции — только один поток),

Избегает взаимной блокировки (deadlock),

Использует только общие переменные и циклы ожидания,

Подходит только для двух потоков.

Инструкция с атомарными операциями и memory_order
Для корректной работы в современных системах флаги должны быть атомарными с правильным упорядочением операций (memory_order), чтобы избежать эффектов переупорядочивания команд компилятором и процессором.

Ограничения
Подходит только для двух потоков,

Из-за ожидания в цикле (busy-wait) расходует CPU,

Менее эффективен в сравнении со встроенными примитивами ОС.
