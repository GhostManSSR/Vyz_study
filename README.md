# Курсовая работа на тему "Адаптивная сложность" для игры Bug
## О проекте

**Bug** — казуальная аркада для Android: игрок ловит жуков, набирая очки на время.  
Ключевая особенность — **адаптивная сложность (DDA, Dynamic Difficulty Adjustment)**: игра подстраивается под навык конкретного игрока, сохраняя баланс между интересом и вызовом.

## Запуск проекта 
1. Клонирование репозитория
```bash
git clone https://github.com/GhostManSSR/Vyz_study.git \
git switch mobile-development
```
2. Cборка debug-версии
```bash
./gradlew assembleDebug
```
3. Установка на подключённое устройство
```bash
./gradlew installDebug
```
4. Запуск приложения
```bash
adb shell am start -n BugBug.androidApp/.MainActivity
```

## Запуск unit тестирования 
```bash
./gradlew testDebugUnitTest
```
